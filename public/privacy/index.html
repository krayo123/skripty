Privacy Policy

Last updated: June 7, 2026

KrayoSkriptz is a Roblox scripts and executors hub. Visitors can browse the site without creating an account. The site is built to show posts, video previews, unlock links, executor links, and advertising placements.

Information We Process

The public site does not ask visitors for names, email addresses, passwords, or payment details. Basic technical information may still be processed automatically by hosting, analytics, embedded media, or advertising providers. This can include browser type, device information, approximate region, IP address, pages visited, and interaction events needed to load content or ads.

Supabase

Supabase is used as the database for site posts. Stored post data can include a YouTube link, a Lootlabs link, optional title or thumbnail data, and timestamps. The admin page uses Supabase Authentication for the site owner; that login is only for managing posts and is not required for normal visitors.

Advertising Partners

KrayoSkriptz uses third-party advertising code. Advertising partners may use cookies, local storage, scripts, redirects, or similar technologies to show ads, measure performance, prevent abuse, and personalize campaigns. These partners control their own data processing and privacy practices.

Embedded Media And External Links

Posts can link to or embed content from external services such as YouTube and Lootlabs. When you open or interact with those services, their own terms and privacy policies apply. KrayoSkriptz is not responsible for the content, tracking, or downloads provided by external websites.

Cookies

Cookies and similar technologies are explained in the Cookie Policy. You can control many of these settings through your browser, but blocking advertising scripts can affect how the site displays ad areas.

Data Choices

You can limit cookies, clear site data, block third-party scripts, or disable personalized ads in your browser or device settings. If you contact the site owner about privacy, include the page URL and a clear description of the request so it can be reviewed.

This page is a practical privacy notice for the project. It should be reviewed again if new analytics, accounts, payment features, or extra data collection are added later.
